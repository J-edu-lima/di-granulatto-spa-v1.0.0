# di-granulatto-spa-v1.0.0
O sistema consiste em uma aplicação full-stack construída com Next.js utilizando App Router e Prisma ORM para acesso ao banco de dados. O sistema tem como objetivo de catalogar os produtos (criando uma loja virtual para o vendedor)  e permitir a realização de pedidos (feitos por clientes) e controle dos pedidos (feitos pelo admin).
